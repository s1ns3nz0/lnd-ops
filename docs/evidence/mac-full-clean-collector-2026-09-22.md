Removed the host's `localhost/lnd-ops-payment-collector:5a32c99aac488a4e` image. Confirmed no Lima instance and no host collector image remained. The Mac's Ubuntu download cache and Docker Buildx layer cache remained.

Fixed the script, removed that namespace, confirmed its absence, and reran `ops/deploy regtest`. 5. `ops/verify regtest` and `ops/verify testnet` each passed infrastructure checks and exited `10` at their manual wallet gates. Confirmed no collector image existed in the new K3s store before building.

Changed `ops/build-collector` to copy the Python base by its locked OCI index digest into the local Docker daemon with `skopeo`, then build from that verified local base. The revised script built `localhost/lnd-ops-payment-collector:8267a178cd50a785` for linux/arm64 and imported it into the new K3s containerd store. Its sidecar runtime still awaits an unlocked wallet.
7. `ops/check-images` passed for all 12 rendered OCI references plus the collector's locked Python base; `npm test` passed three tests, the Python collector suite passed three tests, ShellCheck and `git diff --check` passed, and `ops/verify-monitoring --infrastructure-only` passed. Host `lsof` showed the K3s API listener on `127.0.0.1:6443`.

The first regtest deploy attempt was a discovered failure, not a passing clean-start attempt; the empty namespace was deleted before the passing rerun. The project image was rebuilt from no host tag and no K3s copy, though Docker's layer cache was retained. This proof does not exercise a Windows host or a complete funded-node MVP.
